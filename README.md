# everyday## 計劃摘要

本計劃以 BrainBox 現有的「每日時間軸、月曆、稍後辦、購物清單」為基礎，整合日程與待辦，並新增可愛圖示地圖。設計優先順序是：常用操作容易找到、建立或修改資料步驟短、顏色與圖示能快速辨認、手機單手操作順暢。

## 研究範圍與網站現況

已實際檢視 [BrainBox 網站](https://getbrainbox.app/) 的首頁與主要操作介面。網站目前以單日時間軸呈現一天行程，頂部可切換日期、開啟月曆、搜尋及設定；畫面顯示起床與就寢時間，並計算兩者之間的空檔時數。底部提供「稍後辦」與「購物清單」，也能新增任務。

網站設定中可見的現有功能包括：

- 起床與就寢時間設定、重複任務與生活模式（依班別或休假切換作息）。
- 任務標籤、以資料夾方式管理任務、批次輸入。
- 通知設定、購物清單的時間或地點提醒、稍後辦提醒，以及離開地點時的防遺漏提醒。
- 顯示與語言設定、登入後跨裝置同步、網頁版入口。
- 搜尋可涵蓋任務名稱、備註與分頁；月曆可切換月份、回到今天、依日期查看任務。

本次檢視的首頁沒有地圖模組，也沒有看到月曆事件自訂文字色與背景色的完整操作。因此以下將地圖、色彩自訂和待辦編輯／刪除明確列為本計劃建議新增或補強的功能，而非描述成現有網站已提供的功能。

## 產品目標與核心使用情境

1. 使用者打開首頁，立即看懂今天的安排、空檔與待辦。
2. 使用者可在月曆快速新增、編輯、完成或刪除事件，並用顏色區分不同類型。
3. 使用者可在地圖找附近店家或服務，辨認店家類別、定位目前位置並收藏喜好地點。
4. 行事曆、時間軸與待辦共用同一筆資料，避免重複輸入與資訊不一致。

## 資訊架構與導覽

建議採用手機底部固定導覽列，維持最常用功能一鍵可達：

- **今天**：每日時間軸、空檔時段、今日待辦與快速新增。
- **行事曆**：月／週／日檢視、事件與日期管理。
- **地圖**：目前位置、附近地點、搜尋與已收藏地點。
- **稍後辦**：尚未排定時間的待辦，並可拖放或指定日期。
- **更多**：購物清單、重複任務、標籤／資料夾、通知與設定。

所有頁面保留一致的圓角卡片、清楚的圖示與主要新增按鈕。新增按鈕在底部或拇指容易觸及的位置，點擊後以簡短表單開始，不先要求填寫非必要欄位。

## 功能規格

### 1. 地圖與喜好地點

**地圖主畫面**

- 首次進入時用一句話說明定位用途，點擊「定位我」後才向裝置請求位置權限；拒絕後仍可用搜尋地址或手動移動地圖。
- 目前位置以清楚的「你在這裡」標記顯示，並提供一鍵回到目前位置。
- 提供搜尋框、地圖／清單切換、地點類別篩選，以及目前視野內重新搜尋。
- 店家標記使用同一套可愛插畫風格的小圖示，並配合色彩與文字標籤，避免只靠顏色辨識。

**建議圖示分類**

| 類別      | 地圖圖示例子   |
| ------- | -------- |
| 咖啡店     | 咖啡杯      |
| 餐廳／小吃   | 盤子與刀叉    |
| 服飾店     | 衣服或衣架    |
| 醫院／診所   | 聽診器或醫療十字 |
| 藥局      | 藥丸或藥袋    |
| 超市／便利商店 | 購物籃或購物袋  |
| 公園      | 樹木或長椅    |
| 停車場     | P 標誌與小車  |
| 交通／車站   | 火車或公車    |
| 加油／充電   | 油槍或充電插頭  |
| 銀行／ATM  | 錢包或卡片    |
| 娛樂／電影院  | 電影票或放映機  |
| 美容／理髮   | 梳子或剪刀    |
| 住宿      | 床或小屋     |

地點密集時採用群組標記；放大後才逐一顯示，避免地圖被圖示塞滿。使用者可選擇一般或夜間底圖，標記文字需保有足夠對比。

**地點資訊與收藏**

- 點擊標記後由底部滑出地點卡片，顯示名稱、類別、地址、距離、營業資訊（若資料來源提供）及導航入口。
- 收藏操作以明顯的愛心或書籤按鈕呈現，可新增到「喜好地點」，並選擇自訂清單，例如「想去咖啡店」「常去診所」。
- 收藏後顯示已儲存狀態；再次點擊可取消收藏。清單可搜尋、篩選、重新命名，並可從清單直接在地圖定位。
- 支援手動新增地點：搜尋地址或長按地圖選點，輸入名稱、類別與備註後儲存。
- 若地點也要設提醒，可從地點卡片建立「到達時提醒」或連結一項待辦；定位及背景提醒權限需在使用者啟用該功能時才逐步說明與請求。

### 2. 行事曆與色彩自訂

**檢視方式與快速操作**

- 月曆作為全月概覽；週檢視協助安排時間；日檢視沿用網站每日時間軸與空檔時數概念。
- 點日期可查看當日事件與待辦；長按空白日期或點「＋」可快速新增。
- 事件卡片顯示標題、時間與短色標。若同一天事件過多，保留日期格清爽，點入日期看完整清單。
- 支援全天事件、開始／結束時間、重複規則、提醒、地點、備註及所屬日曆。

**標題與背景顏色**

- 新增或編輯事件時，提供「標題顏色」與「背景顏色」兩個獨立控制項。
- 每種顏色使用圓形色票，選取後以勾號顯示；預設提供無色、柔和藍、綠、黃、橘、粉、灰等易辨識色。
- 最後一個彩色圓盤開啟調色盤，支援拖曳選色、色相／明度調整與 HEX 色碼輸入；提供「最近使用」和「重設」。
- 使用者可將顏色只套用於目前事件，或選擇套用到整個事件類別／日曆。
- 系統需自動檢查文字與背景的可讀性；若對比不足，提示更換文字色或提供自動推薦。顏色之外也保留事件標題、圖示或類別標籤作為辨識線索。

**參考圖片的視覺方向**

參考圖片呈現月曆網格、大而清楚的日期數字、週末日期使用不同文字色、當日醒目底色，以及事件以圓角色籤呈現。色彩選擇畫面使用圓形色票與自訂彩色圓盤；事件編輯以直向排列的欄位和清楚的刪除入口為主。建議保留這些直覺元素，並採柔和粉彩配色、留白與輕量陰影，避免過度裝飾影響閱讀。

### 3. 待辦事項新增、編輯與刪除

- 每筆待辦支援標題、日期／時間、提醒、標籤、備註、地點、重複規則與所屬清單；非必要欄位可稍後補充。
- 點擊待辦可開啟詳情；點擊「編輯」後沿用新增表單，已填資料預先帶入。
- 使用者可直接修改標題、時間、備註、標籤或地點，儲存後即同步更新時間軸、月曆與清單。
- 每筆待辦提供「完成」與「刪除」。刪除先移至垃圾桶或提供短時間復原通知；若含有重複規則，刪除時需清楚選擇「只刪除此筆」或「刪除此筆及後續」。
- 支援將「稍後辦」項目排入指定日期，也支援從地圖地點卡片建立帶有地點的待辦。

### 4. 沿用網站優勢的整合功能

- **每日時間軸與空檔**：繼續以起床／就寢時間呈現一天，並標示可安排任務的空檔。
- **稍後辦**：未排定時間的待辦先集中保存，避免因為尚未決定日期而遺漏。
- **購物清單**：保留獨立清單與時間／地點提醒，並可從地圖附近店家連結清單項目。
- **標籤、資料夾與重複任務**：沿用現有分類和例行安排，讓地圖、月曆、時間軸使用相同分類。
- **搜尋**：一個搜尋入口搜尋任務、備註、標籤、清單與收藏地點。
- **同步**：若使用者登入，行事曆、任務與收藏地點應跨裝置同步；未登入時清楚說明資料保存方式與限制。

## 主要操作流程

### 新增行事曆事件

1. 點選日期或新增按鈕。
2. 輸入標題，必要時設定全天或時間。
3. 選擇標題色與背景色，或開啟自訂調色盤。
4. 可選填地點、提醒、重複規則與備註。
5. 點「儲存」後立即在月曆與當日時間軸看到事件。

### 編輯或刪除待辦

1. 點擊待辦卡片。
2. 在詳情頁選擇「編輯」或「刪除」。
3. 編輯後儲存；刪除則顯示可復原提示，並更新所有相關檢視。

### 尋找並收藏地點

1. 開啟地圖，允許定位或搜尋地點。
2. 點擊插畫標記，查看底部資訊卡。
3. 點擊收藏，選擇既有喜好清單或建立新清單。
4. 下次從「喜好地點」快速搜尋或直接在地圖上查看。

## 視覺與易用性原則

- 延續 BrainBox 現有的簡潔、淺色背景、圓角卡片與柔和青綠主色；參考圖的粉彩色票用於事件分類，不讓全畫面同時高彩度。
- 所有主要功能採清楚文字加圖示，不讓使用者只猜圖示意思。
- 常用按鈕有足夠觸控面積，表單欄位由重要到次要排列，預設值合理且可跳過選填欄位。
- 顏色須有文字標籤、圖示或形狀輔助，支援色覺差異與螢幕閱讀。
- 提供空狀態提示，例如「還沒有收藏地點」「今天沒有待辦」，並直接給下一步按鈕。
- 儲存、完成、刪除、收藏等操作都要有明確回饋；可復原的操作提供「復原」入口。

## 隱私與權限

- 地圖定位只在使用者啟用定位功能時請求；先解釋用途，拒絕權限時仍保留地址搜尋與手動選點。
- 清楚說明定位資料是否只在裝置上使用、是否會保存，以及用於哪些提醒；只保存提供收藏、同步或提醒所需的最少資料。
- 背景地點提醒需獨立開啟並說明耗電與通知用途，讓使用者能隨時停用。
- 登入同步、通知及定位權限分開選擇，不把它們綁成一次性強制授權。

## 驗收重點

- 使用者能在月曆、時間軸與待辦清單新增一筆事件／待辦，並在三個檢視看到同一份資料。
- 修改待辦內容後，所有檢視立即顯示更新；刪除後可在提示期限內復原。
- 事件可分別設定標題色與背景色；色票、自訂色盤、最近使用色及可讀性提示運作正常。
- 使用者可以拒絕定位權限，仍能搜尋地址、瀏覽地圖與收藏手動搜尋到的地點。
- 地圖上常見類別能以圖示辨認，標記不重疊或在縮放時合理群組。
- 收藏地點能加入、取消、分類、搜尋，並在下次開啟後保留。
- 手機直向畫面中，搜尋、定位、收藏、新增與儲存按鈕容易以單手操作。
- 所有主要控制項有文字標示或輔助標籤，顏色不作為唯一辨識方式。
