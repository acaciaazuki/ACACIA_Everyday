✿ ACACIA — 把每一天，過得剛剛好

「你有幾件重要的事，還有足夠的空檔好好呼吸。」

ACACIA 是一款主打「溫柔、無壓力」的個人生活管理 Web App。不同於市面上強調極致效率、容易讓人感到焦慮的生產力工具，ACACIA 將時間管理、待辦事項、記帳本以及地圖探索整合在一個舒適、簡約的介面中。旨在幫助使用者找回生活的節奏，在忙碌與空白之間取得完美的平衡。

🎯 專案理念與目標

溫柔的生產力：不以填滿行事曆為目標，而是自動幫使用者計算「還有多少自由時間」，鼓勵適度留白。

All-in-One 生活中樞：將日常必備的「日程、待辦、記帳、地標收藏」完美整合，不需在多個 App 間頻繁切換。

在地圖上生活：結合真實地圖 API，讓使用者不僅是規劃時間，更能探索、標記並記錄生活周遭的實體空間（如常去的咖啡廳、家附近的超商）。

✨ 核心功能介紹 (Core Features)

1. ◷ 今天 (Today)

每日迎賓面板：根據當前時間給予問候，並動態計算今日的「行程數」、「待辦數」與「自由時間」。

動態時間軸：視覺化呈現當日行程，並在行程之間安插「☁️ 留給自己的空檔」提示。

生活節奏追蹤：設定作息時間（如 07:00-23:00），以進度條直觀顯示當日已安排時數與剩餘空檔。

順手完成 (Quick Tasks)：支援快速輸入，適合記錄腦中隨時閃過的微小待辦。

2. ▦ 行事曆 (Calendar)

直覺的月曆視圖：色彩柔和的月曆介面，點擊日期即可快速瀏覽當日重點行程。

批次任務建立：針對重複性高的日常安排，提供高效的批次選取與登錄功能。

高度客製化：行程事件可自由設定標題文字顏色與卡片背景色。

3. ⌖ 探索地圖 (Map)

真實地圖雙引擎：支援內建高解析 Leaflet/OSM 真實地圖，亦可綁定 Google Maps API 金鑰解鎖官方圖資。

900m 周邊雷達：一鍵高精度定位，並自動掃描周邊 900 公尺內的超商、咖啡廳、餐廳、公園等真實店家。

專屬地標書籤：可將喜愛的地點加入收藏，自訂評分 (1-5 星)、標籤與專屬圖文筆記。

手繪風建築圖示：捨棄傳統大頭針，根據地點類型（咖啡、服飾、醫院等）顯示精緻的 SVG 建築圖示。

4. ☑ 稍後辦 (Tasks)

詳細任務管理：支援記錄任務名稱、地點、預定日期與時間。

色彩分類系統：提供多種標題與背景顏色 swatch，方便以視覺區分任務緊急度或類型。

5. 🛒 購物清單 & 記帳本 (Shopping)

分類記帳：涵蓋「食、衣、住、行、育、樂、其他」七大類別，以不同顏色視覺化區分。

購物軌跡：可記錄購買品項、金額、商店名稱與時間，結合「待購/已購」核取功能，既是清單也是記帳本。

6. ⌘K 全局搜尋 (Command Palette)

無縫搜尋體驗：支援快捷鍵 ⌘K 喚起搜尋框，一鍵全域搜尋行程、待辦、記帳紀錄以及地圖筆記。

🎨 視覺與 UI/UX 設計

色彩計畫 (Color Palette)：

以自然放鬆的「鼠尾草綠 (Sage Green, #4a987b)」為主色調。

搭配薄荷綠 (#dff2e9)、燕麥白 (#f7faf8) 作為背景底色，降低視覺疲勞。

文字採用深墨綠色 (#263633)，提供溫和的對比度。

排版與字體：

採用 DM Sans (英文/數字) 與 Noto Sans TC (中文) 組合，確保現代感與易讀性。

介面大量運用圓角 (14px, 10px) 營造平易近人的圓潤感。

響應式設計 (RWD)：

桌面版：左側固定導航欄 (Sidebar) 搭配右側寬敞的主內容區。

行動版：自動隱藏左側邊欄，切換為底部導航列 (Bottom Nav Bar)，適配單手操作與手機螢幕尺寸。

🛠 技術架構 (Tech Stack)

前端核心：HTML5, CSS3, Vanilla JavaScript (無依賴大型框架，極致輕量化)。

資料儲存：LocalStorage (全端運作於瀏覽器本地，確保隱私安全，支援斷網使用)。

地圖與圖資 API：

預設引擎：Leaflet.js 搭配 CARTO Voyager 底圖。

POI 搜尋：整合 OSM Overpass API 進行周邊真實店家掃描。

擴充引擎：Google Maps API (使用者可輸入自己的 API Key 切換)。

地理編碼：OSM Nominatim API (用於地址搜尋定位)。

圖示系統：純 CSS/SVG 手繪圖示，無需額外載入外部 Font Icons 庫。

🚀 未來發展建議 (Roadmap)

雲端同步功能：後續可整合 Firebase 或 Supabase，讓使用者跨裝置 (手機/電腦) 同步資料。

統計圖表：在記帳本與時間軸加入 Chart.js，視覺化呈現每月花費圓餅圖與時間分配長條圖。

PWA (漸進式網頁應用)：新增 manifest.json 與 Service Worker，讓使用者可將 ACACIA 下載至手機桌面，享有近似 Native App 的體驗。

深色模式 (Dark Mode)：提供深色主題切換，照顧夜間使用的護眼需求。
